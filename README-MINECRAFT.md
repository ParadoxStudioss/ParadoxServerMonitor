# Paradox Server Monitor — Minecraft
Dedicated server mod for Minecraft 1.21.1, NeoForge 21.1.267, Java 21. Install the JAR in server mods, start once, and fill in config/paradoxmonitor.properties; restart. Keep webhook URLs secret. Four independent endpoints: joinWebhook, leaveWebhook, crashWebhook, errorWebhook. Empty disables the endpoint. Reads the server's logs/latest.log, not client files. Abnormal disconnects trigger both leave and crash alerts; timeouts and network failures are suspected, not confirmed crashes. Ordinary kicks are reported as leave if Minecraft logs a left-the-game event. ERROR and FATAL log lines are forwarded (not multiline stack traces). Standard IPv4 and IPv6 and Discord webhook URLs are redacted. The sender uses a bounded in-memory queue and retries transient HTTP failures. No client mod, networking channel or external dependencies. GitHub Actions builds against real NeoForge; run gradle clean build with Java 21 locally. Abrupt server process termination or unlogged client crashes cannot be delivered. The local offline JAR is compiled against annotation-only compatibility declarations, not tested on a running NeoForge server.
